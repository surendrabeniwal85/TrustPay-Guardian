## 2. Execution Roadmap & Branch Strategy

Execution proceeds strictly sequentially from Phase 0 to Phase 16:
1. Re-read PRD sections and phase prompt.
2. Checkout feature branch: `feature/phase-XX-name` from `develop`.
3. Implement missing items and fix deviations.
4. Run all checks, save evidence to `docs/verification/phase-XX.md`.
5. Commit with Conventional Commits, merge to `develop` with `--no-ff`.
6. Update `docs/PROGRESS.md`.
7. Tags: `v0.1.0` after Phase 8, `v1.0.0` after Phase 15.
